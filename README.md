
# Sistema inteligente de diagnóstico tecnológico con Ollama

## Descripción
Aplicación que utiliza un modelo de lenguaje local para
orientar al usuario sobre posibles problemas de equipos
tecnológicos y recomendaciones de mantenimiento.

## Tecnologías
- Python
- Ollama
- Qwen3
- Streamlit

## Funcionamiento
1. El usuario describe el problema.
2. Python envía la consulta a Ollama.
3. El modelo analiza la descripción.
4. La aplicación presenta posibles causas y recomendaciones.

## Pruebas
Se evaluarán cinco situaciones:
- Computador lento.
- Poco espacio de almacenamiento.
- Problemas de Wi-Fi.
- Inicio lento de Windows.
- Teclado externo no reconocido.

## Evidencias
Las capturas de las pruebas se almacenarán
en la carpeta evidencias.
